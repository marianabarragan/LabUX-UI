# Dulce Suspiro · Pastelería

Landing page (one page) hecha en HTML, CSS y JavaScript a partir del diseño en Figma "página postres".

- `index.html`: estructura de la página (escritorio 1920 px y móvil 430 px).
- `estilos.css`: estilos y estados de los componentes (hover, seleccionado, completado).
- `script.js`: escala de la página, header fijo con anclas, carrusel infinito con parallax de limones, tarjetas de Ocasión especial y formulario por pasos.
- `img/`: imágenes y vectores.

## Publicar en GitHub Pages
1. Sube todo el contenido de esta carpeta a un repositorio, con `index.html` en la raíz.
2. En el repositorio, ve a **Settings → Pages**.
3. En "Branch" elige `main` y la carpeta `/ (root)`, y guarda.
4. En un par de minutos la página queda en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/`.
